# Правила работы с Pomodoro Island

- Перед изменением сценария прочитай `PRD.md`. Для интерфейса также прочитай `DESIGN.md`, для входа и хранения — `ARCHITECTURE.md`. Статус итоговой доработки находится в `PLAN-IDZ1-FINAL.md`.
- Запускай проект из корня через `npm run dev`, проверяй типы и сборку через `npm run build`.
- Используй текущие компоненты shadcn/ui и токены `src/styles.css`. Сохраняй собственную SVG/CSS-сцену. Используй одну библиотеку компонентов. Для локального запуска из чистой папки используй npm ci. Сохраняй отсчёт по `endsAt`, непрерывность состояния при навигации, сброс с подтверждением и запуск звука после жеста пользователя.
- Сохраняй старые данные браузера. Изменения формата хранения сопровождай явным планом совместимости. Для облачного режима используй миграции, RLS и RPC. В клиенте допускаются publishable key и пользовательская сессия, секреты остаются в сервисах.
- После изменений пройди затронутый сценарий. Для входа и хранения проверь ошибки, сохранение после обновления и изоляцию двух аккаунтов.
- Обновляй PRD при изменении поведения, DESIGN при изменении оформления, ARCHITECTURE при изменении входа или хранения. В README поддерживай команды запуска. Перед новым чатом запиши решения, проверки и оставшиеся задачи в план.
