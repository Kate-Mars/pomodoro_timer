# PLAN-01: правки интерфейса «Остров» (v1.1)

**Статус:** выполнен (11.11.2026)
**Дата:** 11.11.2026
**Основание:** [PRD.md](PRD.md) (п. 1–9), [DESIGN.md](DESIGN.md) и разбор интерфейса от 11.11.2026
**Объём редакции 1:** тексты статусов, видимый процент острова, подтверждение сброса, кнопка «Очистить остров», подписи звука и поля минут.
**Редакция 2:** добавлены экраны, биомы и музыка — раздел 10 (пп. 10.1–10.11). Разделы 1–9 остаются в силе, кроме явно пересмотренного в п. 10.5.

## 1. Решения

1. **Смена длительности.** На паузе и во время сессии длительность заблокирована, как в PRD. Путь «сократить сессию» — только через «Сброс», теперь с подтверждением. В PRD добавлена строка про то, что длительность меняется только в idle (и completed, см. п. 8).
2. **Подпись прогресса.** Под сценой появляется строка «остров N %». Процент считается как `round(постройки / 14 * 100)` — то же значение, что уходит в `aria-label`.
3. **«Сброс».** В idle и completed кнопка скрыта (не disabled). В running и paused — видима, но открывает диалог «Сбросить сессию? Прогресс острова будет потерян.» с кнопками «Отмена» / «Сбросить».
4. **Готовый остров.** В idle при `progress = 1` статус «Остров достроен». Появляется кнопка «Очистить остров»: сбрасывает только остров в idle, таймер не запускает. «Начать заново» по-прежнему сразу стартует новую сессию.
5. **Формат времени.** Остаётся MM:SS без пересчёта в часы: 180 минут — `180:00`. Решение зафиксировано в PRD, `3:00:00` не вводим.

Дополнительно, из согласованного списка:

- статусы: «Готов к работе» (idle, 0 %), «Остров достроен» (idle, 100 %), «Прогресс восстановлен» (idle, 0 < progress < 1 после загрузки), «Идёт сессия», «Пауза», «Готово»;
- пометка о восстановлении гаснет после первого действия пользователя — старта, сброса или очистки;
- звук получает текстовую подпись: «звук вкл», «звук выкл», «звук недоступен»;
- поле минут: подпись «Минуты», у пресетов нет «мин», после поля — один раз «мин», нативные спиннеры скрыты;
- финальная анимация, композиция острова, контраст иконки звука и подвал уходят на стилевой этап (зафиксировано в PRD, п. 5).

## 2. Целевые состояния

| Состояние | Статус | Кнопки | Длительность | Подпись под сценой |
|---|---|---|---|---|
| idle, 0 % | Готов к работе | Старт | доступна | остров 0 % |
| idle, частично восстановлен | Прогресс восстановлен | Старт | доступна | остров N % |
| idle, 100 % | Остров достроен | Старт, Очистить остров | доступна | остров 100 % |
| running | Идёт сессия | Пауза, Сброс | заблокирована | остров N % |
| paused | Пауза | Продолжить, Сброс | заблокирована | остров N % |
| completed | Готово | Начать заново, Очистить остров | доступна | остров 100 % |
| degraded: localStorage | без изменений | без изменений | доступна | без изменений |
| degraded: нет Web Audio | без изменений | звук недоступен (disabled) | доступна | без изменений |

«Прогресс восстановлен» — одна строка статуса, отдельной второй подписи не будет, чтобы не дублировать текст. Флаг живёт в памяти и не пишется в localStorage.

## 4. Диалог подтверждения

- Заголовок: «Сбросить сессию?»
- Описание: «Прогресс острова будет потерян.»
- Кнопки: «Отмена» (по умолчанию) и «Сбросить».
- Таймер во время открытого диалога продолжает идти: таймер не трогаем.
- Если сессия успела завершиться при открытом диалоге, подтверждение просто уводит в idle с нулевым островом.

## 5. Процент острова

- `percent = round(visiblePieces / 14 * 100)`, где `visiblePieces` — постройки с `progress >= порог`.
- Значение одно: и видимая подпись, и `aria-label` сцены.
- До первого блока (progress < 0.05) подпись показывает «остров 0 %», после первого — «остров 7 %» (1 из 14).
- Цвет и размер подписи — минимальные, стилевой этап их доработает.

## 6. Что не меняется

- Таймер, `useTimer`, `usePersistedState`, `useAmbientAudio`.
- Схема и ключ localStorage, троттлинг записи.
- Блокировка длительности в running и paused.
- Формат MM:SS.
- Ни одной новой функции сверх перечисленных.

## 7. Проверки после выполнения

1. Холодный старт: «Готов к работе», «остров 0 %», «Сброса» нет; пресеты «15/25/50», поле «Минуты», один «мин», спиннеров нет.
2. Перезагрузка с частичным островом: «Прогресс восстановлен» и процент по постройкам; после «Старт» статус «Идёт сессия», пометка не возвращается.
3. Running: «Сброс» видим → диалог; «Отмена» закрывает и не сбрасывает, отсчёт не сбивается; «Сбросить» → idle, полная длительность, `остров 0 %`, в хранилище `progress: 0`.
4. Completed: «Готово», «Начать заново» + «Очистить остров», «Сброса» нет; «Очистить остров» → idle 0 %, таймер не пошёл; «Начать заново» → сразу running.
5. Перезагрузка после завершения: «Остров достроен», «остров 100 %», есть «Очистить остров».
6. Звук: «звук вкл» / «звук выкл» переключаются, состояние сохраняется; при недоступном Web Audio кнопка disabled с текстом «звук недоступен».
7. `npm run build` без ошибок; 1280×900 и 390×844 без скролла и обрезки.
8. Клавиатура и скринридер: диалог открывается, фокус в нём, Esc закрывает, фокус возвращается на «Сброс»; статусы объявляются через `aria-live`.

## 8. Риски и открытые уточнения

- **Длительность в completed.** Формулировка «меняется только в idle» конфликтует с таблицей PRD, где в completed контролы доступны. План: в running и paused блокируем, в idle и completed разрешаем (иначе после завершения нельзя выбрать другую длительность, не потеряв остров). Если нужно блокировать и в completed — поправить до начала работ.
- **Фокус после «Очистить остров».** Кнопка исчезает из разметки: фокус уйдёт на body. Компенсация — перевести фокус на «Старт».
- **Процент шагами.** 0, 7, 14, 21… — шаг 7 %, а не 1 %, потому что считается по постройкам. Так и задумано в решении 2.
- **Диалог и завершение сессии.** Если таймер дошёл до нуля при открытом диалоге, состояние станет completed; подтверждение сбросит остров в idle.

## 10. Редакция 2 (11.11.2026): экраны, биомы, музыка

### 10.1 Решения

- **Роутинг:** `react-router-dom` 7 (`BrowserRouter`). Экраны получают URL, работают «назад/вперёд» и прямые ссылки. Отклонена навигация только через состояние: теряются ссылки и возврат браузера.
- **Экраны:** четыре — «Таймер», «Настройки», «Прогресс», «О приложении».
- **Навигация:** верхняя панель на десктопе, нижняя на мобильном (≤ 640 px): четыре пункта с иконками и короткими подписями.
- **Биомы:** три, только палитры через CSS-переменные; формы построек общие; выбор — отдельным ключом, не в прогрессе.
- **Музыка:** три процедурных трека, по одному на биом, кроссфейд 1.5 с; громкость 0.0–1.0.
- **Журнал сессий:** счётчики и последние 20 сессий в хранилище, экран показывает 5.
- **«Очистить остров»:** остаётся на «Таймере» (контекст: достроенный остров) и дублируется в «Настройках»; там же «Сбросить прогресс» — остров и журнал.
- **Порядок:** четыре этапа, после каждого — проверка и только потом следующий.

### 10.2 Каркас экранов

| Маршрут | Экран | Ключевое содержимое |
|---|---|---|
| `/` | Таймер | сцена, `остров N %`, таймер, длительность, пауза/сброс, звук |
| `/settings` | Настройки | длительность по умолчанию, биом, громкость, музыка со стартом, очистка острова, сброс прогресса |
| `/progress` | Прогресс | завершено, суммарное время, остров N %, последние 5 сессий |
| `/about` | О приложении | справка, данные, звук |

Архитектура: `main.tsx` — `BrowserRouter`; `App` держит все хуки (таймер, persisted-состояние, звук, журнал), рисует навигацию и `<Routes>`; экраны получают данные через контекст. Таймер не пересоздаётся при переходах.

Навигация: `NavLink`, `aria-current="page"`, активный пункт цветом `--accent`. На мобильном панель фиксируется снизу с отступом `safe-area`, у контента — нижний отступ под неё.

### 10.3 Настройки

| Настройка | Поведение | Хранение |
|---|---|---|
| Длительность по умолчанию | пресеты «15/25/50» + «Минуты»; заблокирована, пока идёт или стоит пауза | `pomodoro.v1`, `settings.durationMinutes` |
| Биом | три карточки со свотчами: «Луг», «Песок», «Снег»; применяется сразу | `pomodoro.biome.v1` |
| Громкость | ползунок 0–100 % с числом; недоступен без Web Audio | `pomodoro.audio.v1`, `volume` |
| Музыка вместе со стартом | переключатель, по умолчанию включён | `pomodoro.audio.v1`, `musicOnStart` |
| Очистить остров | подтверждение, `progress = 0`, таймер не запускается | `pomodoro.v1` |
| Сбросить прогресс | подтверждение: остров + журнал сессий + счётчики; биом и звук остаются | `pomodoro.v1`, `pomodoro.sessions.v1` |

Длительность в настройках подчиняется тому же правилу, что и на «Таймере»: меняется в idle и completed, во время сессии заблокирована.

### 10.4 Прогресс и журнал сессий

Экран: три плитки (завершено, суммарное время, текущий остров N %), ниже таблица последних 5 сессий: дата и время, длительность, биом, «завершена» / «прервана». Пустое состояние: «Пока нет сессий — начните первую на экране „Таймер“».

Правила записи:

- старт сессии фиксирует `startedAt`, `durationMinutes`, биом;
- завершение — `status: "completed"`, `elapsedMs = durationMinutes * 60000`;
- подтверждённый «Сброс» в running/paused — `status: "aborted"`, `elapsedMs` = прошедшая часть;
- перезагрузка и закрытие страницы сессию не записывают;
- «Очистить остров» журнал не трогает;
- хранятся последние 20, экран показывает 5;
- `stats.completed` и `stats.totalFocusMs` считают только завершённые.

### 10.7 Музыка

- `src/lib/tracks.ts` — описание трёх треков: основа, аккорд, тембр, фильтр, тип пространства, шаг арпеджио.
- `useAmbientAudio` переписывается в движок: граф на трек (3 осциллятора-пада с расстройкой, планировщик арпеджио с опережением 100 мс, lowpass, ConvolverNode с процедурным импульсом или дилей), мастер-гейн, кроссфейд.
- Громкость: `gain = volume^1.5 * 0.10`; mute — 0.3 с; пауза — 0.4 с; кроссфейд биома — 1.5 с.
- Сохранение: `volume` и `musicOnStart` в `pomodoro.audio.v1`, mute — в `pomodoro.v1`.
- Автозапуск: `AudioContext` создаётся только по жесту; при `musicOnStart = false` музыка ждёт кнопку звука.
- Смена биома на паузе — новый трек готов, но тишина до «Продолжить».
- Откат: если движок окажется тяжёлым — один трек («Луг») и заглушки на остальные, зафиксировать в PRD как «потом».

### 10.11 Риски и допущения

- **Состояние при переходах.** Все хуки живут в `App`; экраны только читают контекст, иначе таймер будет сбрасываться.
- **BrowserRouter.** Для локальной работы хватает; при выкладке на статический хостинг нужен fallback на `index.html` или переход на HashRouter — зафиксировать перед публикацией.
- **react-router-dom 7** совместим с React 19; версия в зависимостях фиксируется.
- **Биомы и SVG.** Если заливки останутся инлайновыми, CSS-переменные не подействуют — на этапе 3 их нужно заменить на классы/`var()`.
- **Нагрузка звука.** Одновременно звучит только активный граф; старый останавливается после кроссфейда, планировщик очищается.
- **Автоплей.** Без жеста звука не будет; при `musicOnStart = false` первый звук — по кнопке.
- **Запись громкости.** Сохранять не на каждый пиксель ползунка, а с задержкой ~150 мс.
- **Сессия при перезагрузке** не записывается — так решено; в журнале её не будет.
- **Mute и громкость** независимы: mute главнее, громкость 0 не меняет состояние mute.
