# Как проверить итоговую версию

Установите зависимости и настройте Supabase по [README](../README.md). `npm ci`, затем `npm run dev`, откройте http://localhost:5173. Для Google-входа нужен тестовый аккаунт с доступом к OAuth-проекту. Для входа по email используйте доступный тестовый ящик и подтверждение по ссылке.

Запустите минутную сессию, поставьте её на паузу и продолжите. После завершения откройте журнал по ссылке в панели. Обновите страницу и перезапустите Vite. С тем же аккаунтом проверьте, что запись и выбранный биом сохранились. В [чек-листе](CHECKLIST.md) отмечены реально выполненные проверки и оставшиеся сценарии. Скрипты в checks и старые скриншоты относятся к локальной версии.
