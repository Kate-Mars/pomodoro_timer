# Референсы и концепт

Папка показывает выбранное визуальное направление (Minecraft-inspired cozy study, Pomodoro Island) и то, как оно реализовано.

| Файл | Что это |
|---|---|
| `ref-01.jpg` … `ref-08.jpg` | **Внешние референсы**, которые приложила автор проекта: воксельные парящие острова, дом на блоке, skyblock-деревня, уютный помодоро-интерфейс поверх пейзажа, тёмный минималистичный таймер. Это не скриншоты приложения. |
| `moodboard.jpg` | Те же референсы на одном листе |
| `before-original-version.png` | **Исходная версия приложения до доработки** (плоский остров, тёмная карточка таймера). Это не референс, а точка «до» |
| `reference-vs-result.jpg` | Сравнение: сверху референсы, снизу скриншоты итоговой реализации |

Что взято из референсов: изометрический парящий остров с почвой и камнем снизу, пруд и водопад, дом с трубой, деревья-кубы, тёплый свет окон, интерфейс таймера поверх мира.
Что сделано по-своему: вся графика нарисована кодом (SVG), персонаж и постройки собственные. Текстуры, логотипы и персонажи Minecraft не используются.
